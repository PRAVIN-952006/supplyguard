# Security policy

SupplyGuard is defensive tooling for auditing local SBOM documents. Do not use it to inspect data you are not authorized to access.

Report a suspected vulnerability privately to the repository maintainer rather than opening a public issue with exploit details. Include a minimal reproduction, affected version, impact, and suggested mitigation. Do not include secrets or personal data.

SupplyGuard does not provide vulnerability intelligence or a guarantee that a passing SBOM is safe.
